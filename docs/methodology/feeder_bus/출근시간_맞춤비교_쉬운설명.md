# 출근 시간 맞춤 비교: 광역버스가 줄어든 시간 = GTX역행 마을버스가 늘어난 시간?

## 1. 무엇을 보려는 분석인가

챕터 1에서 **"GTX역 근처 격자에서 광역버스 승차가 줄었다"**는 결과가 나왔다.
하지만 줄어든 승객이 **GTX로 갔다는 근거**는 없었다.

이 분석은 그 근거를 하나 더 찾는 것이다.

> **광역버스가 줄어든 시간대와, 마을버스로 GTX역에 가는 승차가 늘어난 시간대가 같은가?**

- **같다면** (특히 둘 다 아침 출근 시간이면)
  → "광역버스 대신 마을버스를 타고 GTX역에 가서 출근했을 가능성"과 맞는 모습
- **다르다면**
  → 두 변화는 따로 일어난 것

예) 어떤 동네에서 아침 7시 광역버스 승객이 100명 줄었는데, 같은 시간에 GTX역으로 가는 마을버스 승객이 100명 늘었다면 → "버스로 서울 가던 사람들이 마을버스 + GTX로 바꿨나?" 하고 생각해 볼 수 있다.

## 2. 방법

### 자료
| 자료 | 내용 |
|---|---|
| 광역버스 | 기존 24개 노선 교통카드 (챕터 1과 같은 자료, 합계 일치 확인) |
| 마을·시내버스 | GTX 연계 노선 교통카드 (공공데이터포털 지역별 교통카드 합성데이터 API로 수집) |
| 날짜 | 2024-10-17 (개통 전) / 2025-11-06 (개통 후), 하루씩 |
| 대상 | 126개 격자 (운정중앙 63, 킨텍스 26, 대곡 37), 승차 **건수** 기준 |

### 정의
- **GTX역행 마을버스**: 126개 격자 정류장에서 타서, 이름에 **"운정중앙역 · 킨텍스역 · 대곡역"**이 들어간 정류장에서 내린 승차
- **출근 시간**: 06:00 ~ 09:59 (챕터 1·2와 같은 기준)

### 분석 단계
1. **시간대별 비교**: 권역 × 1시간 단위로 광역버스 변화와 GTX역행 마을버스 변화를 나란히 놓는다
2. **출근 집중도**: GTX역행 마을버스 중 출근 시간에 탄 비율을, 같은 노선 전체의 출근 비율과 비교한다
3. **격자 단위 상관**: 출근 시간 / 그 외 시간을 나눠서, "광역버스가 많이 준 격자일수록 GTX역행 마을버스가 많이 늘었나"를 **순위상관**으로 본다

### 왜 OLS가 아닌가
광역버스 변화와 마을버스 변화는 **둘 다 개통 후에 생긴 결과**다.
하나를 원인(독립변수)으로 놓으면 해석이 오염된다.
→ 그래서 **"함께 나타났나"**만 보는 기술통계와 상관을 쓴다.

## 3. 결과

### ① 시간대별 변화 (2025 − 2024, 하루 승차 건수)

|---|---|---|---|---|---|---|---|---|
| **운정** | 광역 | −36 | −125 | **−174** | −84 | −73 | −180 | −672 |
| | GTX역행 | +15 | +96 | **+238** | +107 | +47 | +168 | +671 |
| **킨텍스** | 광역 | −23 | **−151** | −113 | −73 | −58 | −457 | −875 |
| | GTX역행 | 0 | +6 | +10 | +2 | +6 | +27 | +51 |
| **대곡** | 광역 | −9 | −15 | +52 | −8 | +10 | −76 | −46 |
| | GTX역행 | +4 | +10 | +27 | **+35** | +9 | +73 | +158 |

그림: `figures/H10_시간대별_광역vsGTX역행.png` (0~23시 전체), `figures/H10_출근시간대(5~10시)_광역vsGTX역행.png` (출근 전후 확대) (빨강 = 광역 변화, 파랑 = GTX역행 마을버스 변화, 회색 = 출근 시간)

### ② 출근 시간 집중도

| | 운정 | 킨텍스 | 대곡 |
|---|---|---|---|
| GTX역행 마을버스 중 출근 시간 비율 (2025) | **73%** | 36% | 51% |
| 같은 노선 전체의 출근 시간 비율 (2025) | 54% | 30% | 47% |

→ 운정은 GTX역행 마을버스가 **보통 마을버스보다 훨씬 더 아침에 몰려** 있다.

### ③ 격자 단위 순위상관 (광역 변화 vs GTX역행 마을버스 변화)

음수(−) = 광역버스가 많이 준 격자일수록 GTX역행 마을버스가 많이 늘었다

| | 출근 시간 | 그 외 시간 |
|---|---|---|
| 운정 (63격자) | **−0.40 (p 0.001)** ✅ | −0.19 (p 0.14) |
| 킨텍스 (26격자) | −0.20 (p 0.34) | −0.26 (p 0.20) |
| 대곡 (37격자) | −0.32 (p 0.054) | −0.35 (p 0.035) ✅ |
| 전체 (126격자) | **−0.27 (p 0.002)** ✅ | −0.20 (p 0.03) ✅ |

### 순위상관 읽는 법
- 126개 격자를 **광역버스 변화** 순서로 한 줄, **GTX역행 마을버스 변화** 순서로 한 줄 세운 뒤, 두 순서가 얼마나 비슷한지 본다
- 값은 −1 ~ +1
  - **−1에 가까움**: 광역버스가 많이 줄어든 격자일수록 GTX역행 마을버스가 많이 늘었다
  - **0 근처**: 아무 관계 없음
  - **+1에 가까움**: 광역버스가 늘어난 격자일수록 마을버스도 늘었다
- 크기 기준(대략): 0.1 약함 / 0.3 보통 / 0.5 이상 강함
- p값 < 0.05면 "우연이라 보기 어렵다"
- 숫자 크기 대신 **순서**만 보므로, 한두 격자가 아주 큰 값이어도 결과가 흔들리지 않는다 (0이 많은 자료에 적합)
- 예: 운정 출근 시간 −0.40 → "보통 정도로, 광역버스가 많이 준 격자에서 GTX역행 마을버스가 많이 늘었다"
- **원인은 말할 수 없다**: 두 변화 모두 개통 후 결과이므로 "함께 나타났다"까지만

### 점검: 마을·시내버스 공급구조가 유지된 격자만 (92개)
- 기준: 광역버스 공급구조 판정과 같게 — 격자 정류장에서 승차기록이 있는 노선 집합이 두 날짜에 같고, 노선별 정류장이 대응됨(이름 우선, 100m 이내)
- 운정은 신설 노선이 핵심이라 63개 전부 사용, 대곡 19개·킨텍스 10개
- 출근 시간 전체 순위상관 **−0.37 (p < 0.001)**, 그 외 시간 −0.18 (p 0.08) → **출근 시간에만 유의**, 결과 유지

## 3-2. GTX역행 마을버스는 어떤 격자에서 늘었나 (OLS)

### 모형
- **종속변수**: Δ GTX역행 마을·시내버스 승차(건) = 2025 − 2024
  - 126개 격자 정류장에서 마을·시내버스를 타서, 역명 정류장에서 내린 승차
  - 예: 격자 A — 2024년 0건, 2025년 83건 → +83
  - 126개 중 80개는 0 → 0 (증가 없음). 빼지 않고 그대로 넣는다 (빼면 "늘어난 격자"만 남아 비교가 안 됨)
- **독립변수 (모두 개통 전 값)**
  - log(1+GTX역 보행시간), 20~50대 인구, log(1+건축물 연면적), 주거지역 비율
  - 경쟁 목적지·광역버스 통행시간·IC 도로거리는 **광역버스 승객의 사정**이라 뺐다
- 126개 격자, OLS, HC3 표준오차 (챕터 1과 같은 틀)

### 결과
| 변수 | 주모형 (126) | 점검① +역 고정효과 | 점검② 마을버스 승차 있는 91격자 | 점검③ 공급구조 유지 92격자 |
|---|---|---|---|---|
| log(1+보행시간) | **−5.9 (p .009)** ✅ | −8.8 (p <.001) ✅ | −7.7 (p .014) ✅ | −8.1 (p .014) ✅ |
| 20~50대 인구 | −0.010 (p .023) ✅ | −0.006 (p .12) | −0.009 (p .10) | −0.012 (p .017) ✅ |
| log(1+건축물 연면적) | **+8.6 (p .006)** ✅ | +7.1 (p .013) ✅ | +9.2 (p .010) ✅ | +10.1 (p .018) ✅ |
| 주거지역 비율 | +0.05 (p .21) | +0.06 (p .12) | +0.07 (p .19) | +0.06 (p .27) |
| 수정 R² | 0.19 | 0.31 | 0.19 | 0.27 |

VIF 모두 2.6 이하.

### 읽는 법
- **보행시간 −**: 역에서 멀수록 GTX역행 마을버스가 덜 늘었다
- **연면적 +**: 건물(아파트 등)이 많은 격자일수록 더 늘었다
- 이 두 결과는 점검 모형 네 개 모두에서 유지된다
- 20~50대 인구 −는 예상과 반대이고 점검 모형에서 흔들린다 → 연면적과 겹치는 부분 때문일 수 있어 **해석하지 않는다**

### 챕터 1과 나란히 보면
| | 챕터 1 | 이번 |
|---|---|---|
| 종속변수 | Δ 광역버스 승차 | Δ GTX역행 마을버스 승차 |
| 보행시간 | + (멀수록 덜 줄었다) | − (멀수록 덜 늘었다) |
| 뜻 | **역 가까운 곳에서 변화가 컸다** | **역 가까운 곳에서 변화가 컸다** |

## 4. 권역별 해석

| 권역 | 모습 | 해석 |
|---|---|---|
| **운정** | 광역 감소와 GTX역행 증가가 **같은 시간(아침 7시), 같은 격자, 비슷한 크기(약 670건)** | 가설과 가장 잘 맞음 |
| **킨텍스** | 광역은 875건 줄었는데 GTX역행 마을버스는 51건만 늘어남 | 마을버스로 역에 간 모습은 안 보임 (걸어서 갔거나, 다른 이유일 수 있음) |
| **대곡** | 광역은 거의 안 줄었는데 GTX역행 마을버스는 늘어남 | 대곡역엔 지하철(3호선·경의중앙선)도 있어서 GTX 이용인지 구분 불가 |

## 5. 한 줄 정리

> **운정 권역에서는 광역버스 감소와 GTX역행 마을버스 증가가 같은 시간(아침 출근), 같은 격자, 비슷한 크기로 나타났다.** 광역버스 대신 마을버스로 GTX역에 가서 출근했을 가능성과 맞는 모습이다. 킨텍스·대곡에서는 이런 모습이 뚜렷하지 않았다.
>
> **GTX역행 마을버스는 역에서 가깝고 건물이 많은 격자에서 더 늘었다** (OLS, 개통 전 변수, 점검 모형에서도 유지).

## 6. 한계 (논문에 꼭 같이 쓸 것)

- **같은 사람인지 모른다**: 날짜가 다르면 카드번호를 연결할 수 없다 → "옮겨갔다"고 말할 수 없고 "함께 나타났다"까지만
- **하루치 비교**다
- 신설 **시내버스 4개 노선(80·101·202·84)**은 카드 노선 ID를 찾지 못해 빠져 있다
- 2024년 마을버스 수집 자료는 전국 원자료의 약 50% 수준이다 (격자 순위상관 0.87)
- 역명 정류장 중 "양우아파트.대곡역롯데캐슬"처럼 아파트 이름에 역명이 붙은 곳도 일부 포함된다 (건수 적음)
