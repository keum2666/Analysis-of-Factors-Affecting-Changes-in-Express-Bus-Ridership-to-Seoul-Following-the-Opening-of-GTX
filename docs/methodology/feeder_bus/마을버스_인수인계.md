# 마을버스(챕터 2) 인수인계 — GTX역행 마을·시내버스 분석

먼저 이 문서를 읽고, 자세한 결과·해석은 `건수기준_재분석/10_가설검증/마을버스분석_정리.md` 를 본다.

## 1. 연구 한 줄 요약
GTX-A 개통 전후(하루치: 2024-10-17 vs 2025-11-06), 250m 격자 126개(운정중앙 63, 킨텍스 26, 대곡 37)에서
**어떤 격자에서 GTX역으로 가는 마을·시내버스를 많이 타는지** OLS로 본다.

- 챕터 1 = 광역버스 격자 OLS (`04_OLS/`, 다른 사람 작업 — **수정 금지, 읽기만**)
- 챕터 2 = 이 작업 (GTX역행 마을·시내버스)

## 2. 고정 조건 (바꾸지 말 것)
- 날짜 2개, 격자 126개 고정. **권역·날짜 늘리는 제안 금지**
- 승차는 `utztn_nope` 합이 아니라 **승차 건수(행 수)** 기준 (이유: `건수기준_전환_사유.md`, 수정 금지)
- 분석 방법은 **OLS (HC3 표준오차)** 만
- 개통 후 변화량(Δ)은 독립변수로 넣지 않음 (예외: 챕터 2는 종속이 2025 건수라 인구도 2025 사용)
- 개통 전 마을버스 이용(TCN) 변수는 쓰지 않기로 함
- 표현: 인과·"전환/옮겨갔다" 금지 → "함께 나타났다", 먼 곳은 "광역 이용이 상대적으로 유지"
- 세 권역을 똑같은 비중으로 서술
- 다른 사람 폴더(`04_OLS/`, `05_변수확장/`)와 `건수기준_전환_사유.md` 는 수정 금지

## 3. 종속변수 정의
**GTX역행 마을·시내버스 승차(건)** = 126격자 안 정류장에서 승차 → 하차 정류장 이름에 `운정중앙역`·`킨텍스역`·`대곡역` 이 들어간 경우.
역 정류장 → 역 정류장 승차는 제외. 광역버스 24개 노선은 제외(마을·시내버스만).
- 주모형 종속 = **2025 건수** (2024는 126격자 중 113개가 0건이라 변화량보다 개통 후 수준이 맞음)
- 2025 총 1,015건 (승차 권역: 운정 672, 대곡 230, 킨텍스 113) / 2024 총 135건

## 4. 주모형 (n=126, OLS HC3) — `code/s10_12_feeder_final.py`
종속 = 2025 GTX역행 승차 건수

| 변수 | 계수 | p |
|---|---|---|
| 상수 | 31.35 | .027 |
| log(1+GTX역 보행시간) | −8.80 | .005 |
| 20~50대 인구 2025 | −0.002 | .70 |
| log(1+건축물 연면적) | +7.56 | .026 |
| 주거지역 비율 | +0.03 | .72 |
| 1km 안 기존 철도역 수 (0/1/2, log 안 씀) | −4.58 | .085 |
| 운정 더미 (운정중앙=1) | +8.23 | .034 |

R² .276, 수정 R² .240, F 4.91, LOOCV R² .170, VIF ≤ 2.70

- 철도역 수: `05_변수확장/tables/S5_후보변수_126격자.csv` 의 `n_rail_1km` (GTX 전용역 제외 OSM 철도역)
- 운정 더미 근거: 현장 답사에서 운정중앙역 환승센터 확인 + 연계 노선 신설·경로 변경이 운정에 몰림
