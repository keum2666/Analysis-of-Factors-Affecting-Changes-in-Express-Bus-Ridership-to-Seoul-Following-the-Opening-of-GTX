# 포아송·음이항 회귀분석 용어 정리

## 1. 포아송 회귀

승차인원처럼 0 이상의 정수로 된 횟수 자료를 분석하는 회귀모형이다. 포아송 모형은 평균과 분산이 같다고 가정한다.

`E(Y) = Var(Y)`

## 2. 포아송 QMLE

QMLE는 준최대우도추정법(Quasi-Maximum Likelihood Estimation)이다. 포아송 분포를 정확히 따르지 않더라도 평균 구조를 추정하고, 강건 표준오차를 사용해 효과와 p값을 계산하는 방법이다.

```text
포아송 QMLE = 평균 구조 추정 + 강건 표준오차
```

## 3. 음이항 회귀와 NB2

음이항 회귀는 평균보다 분산이 큰 횟수 자료를 분석하는 모형이다. 본 연구에서 사용한 NB2 모형은 다음과 같다.

`Var(Y) = μ + αμ²`

- `μ`: 예상 승차인원
- `α`: 과산포를 조정하는 분산 모수

## 4. 과산포

과산포는 종속변수의 분산이 평균보다 큰 상태이다.

`분산 > 평균`

과산포가 있으면 포아송 모형의 표준오차가 작게 계산되어 p값이 실제보다 작아질 수 있다. 따라서 포아송 QMLE를 사용하거나 음이항 모형과 비교해야 한다.

### Pearson dispersion

`Pearson dispersion = Pearson χ² / 자유도`

값이 1에 가까우면 포아송 가정과 큰 차이가 없고, 1보다 훨씬 크면 과산포가 있다는 뜻이다.

### Deviance/df

`Deviance/df = Deviance / 잔차 자유도`

이 값도 1에 가까운지를 확인한다. 1보다 훨씬 크면 포아송 모형이 자료의 변동을 충분히 설명하지 못할 가능성이 있다.

## 5. Offset

원래 규모의 차이를 통제하는 값이다. 본 연구에서는 2024년 승차인원을 offset으로 사용한다.

`offset = log(Y2024)`

offset의 계수는 1로 고정된다. 따라서 원래 승객이 많은 셀·노선과 적은 셀·노선을 규모 차이를 고려해 비교한다.

본 연구의 기본 구조는 다음과 같다.

```text
log(E[Y2025]) = log(Y2024) + βX + 노선 고정효과
```

## 6. 노선 고정효과

노선마다 존재하는 기본적인 이용량·운행특성 차이를 통제하는 방법이다. 노선 고정효과를 넣으면 같은 노선 안에서 GTX 접근성이 다른 셀·정류장을 비교하는 의미가 된다.

## 7. 계수와 IRR

포아송·음이항 회귀의 계수는 로그 승차인원에 대한 효과이다. 따라서 지수변환해 해석한다.

```text
IRR = exp(계수)
상대적 효과율(%) = (exp(계수) - 1) × 100
```

예를 들어 계수가 `-0.815`이면 IRR은 약 `0.441`, 상대적 효과율은 약 `-55.9%`이다.

해석:

> 다른 조건이 같을 때, 해당 조건의 예상 승차인원은 비교 기준보다 약 55.9% 낮았다.

## 8. 더미변수와 기준집단

보행시간 구간은 다음처럼 구성된다.

| 보행시간 구간 | 보행 20분 이내 | 보행 20~60분 |
|---|---:|---:|
| 20분 이내 | 1 | 0 |
| 20~60분 | 0 | 1 |
| 60분 초과 | 0 | 0 |

`60분 초과`가 기준집단이다. 따라서 각 계수는 60분 초과 지역과 비교한 효과이다.

## 9. p-value와 z값

p값은 귀무가설이 맞다고 가정했을 때 현재와 같은 결과가 우연히 나타날 가능성이다.

- `p < 0.01`: 매우 유의
- `p < 0.05`: 유의
- `p < 0.10`: 약한 유의성

z값은 계수를 표준오차로 나눈 값이다.

`z = 계수 / 표준오차`

z값의 절댓값이 클수록 계수가 0에서 멀리 떨어져 있으며, p값 계산에 사용된다.

## 10. 로그우도

로그우도(Log-Likelihood)는 쉽게 말하면 **모형 전체의 적합도 채점 점수**이다. 각 셀×노선에서 실제로 관측된 승차인원이 해당 모형에서 나타날 가능성을 계산하고, 모든 관측치의 점수를 합한 값이다.

예를 들어 실제 승차인원이 100명일 때 100명 근처가 나올 가능성을 높게 제시한 모형은 높은 점수를 받고, 20명 근처가 나올 가능성을 높게 제시한 모형은 낮은 점수를 받는다. 이러한 채점을 전체 220개 셀×노선에 대해 합한 것이 로그우도이다.

확률은 0과 1 사이이고, 1보다 작은 확률에 로그를 취하면 음수가 되므로 로그우도는 일반적으로 음수로 나타난다. 음수라는 사실 자체는 모형이 나쁘다는 뜻이 아니다.

### 해석 방법

- 로그우도에는 `몇 이상이면 좋은 모형`이라는 절대적인 합격 기준이 없다.
- 하나의 모형만 보고 적합 여부를 판단하는 지표가 아니라, **같은 자료와 같은 종속변수를 사용한 모형끼리 비교하는 지표**이다.
- 비교할 때는 값이 큰 모형, 즉 음수의 절댓값이 작고 0에 더 가까운 모형의 적합도가 상대적으로 높다.
- 표본 수나 종속변수가 다르면 로그우도 크기도 달라지므로 서로 직접 비교하면 안 된다.

본 연구의 예시는 다음과 같다.

| 모형 | 로그우도 | 비교 결과 |
|---|---:|---|
| 포아송 | -1,732.69 | 상대적으로 낮음 |
| 음이항 NB2 | -938.43 | 상대적으로 높음 |

`-938.43 > -1,732.69`이므로 동일한 220개 셀×노선 자료에서는 음이항 NB2 모형이 포아송 모형보다 실제 승차인원 자료에 더 잘 맞는다고 해석한다. 그러나 `-938.43`이라는 숫자 자체만으로 모형이 좋거나 나쁘다고 판단하지 않는다.

### 다른 지표와의 역할 차이

| 지표 | 주된 역할 | 판단 방법 |
|---|---|---|
| p-value | 특정 독립변수가 통계적으로 관련 있는지 판단 | 일반적으로 0.05 미만이면 유의 |
| OLS R² | 종속변수 분산의 설명 정도 | 클수록 높음 |
| Pseudo R² | 기준모형보다 적합도가 얼마나 개선됐는지 평가 | 클수록 개선 정도가 큼 |
| 로그우도 | 같은 자료로 추정한 모형 전체의 상대적 적합도 비교 | 큰 값, 즉 덜 음수인 값이 우수 |
| AIC·BIC | 적합도와 모형 복잡성을 함께 고려한 비교 | 낮을수록 우수 |

변수를 추가하면 로그우도는 대체로 높아지므로 로그우도만으로 최종모형을 선택하지 않는다. 변수 개수에 불이익을 주는 AIC·BIC, 과산포 모수 alpha, LR 검정, 수렴 여부 및 핵심 변수의 계수·IRR·p값을 함께 확인한다.

## 11. AIC와 BIC

AIC와 BIC는 여러 회귀모형의 적합도를 비교하는 지표이다. 모형의 적합도뿐 아니라 변수 개수와 복잡성도 함께 고려한다.

`값이 낮을수록 더 적합한 모형`

- `AIC`: 적합도와 모형 복잡성의 균형을 평가
- `BIC`: AIC보다 복잡한 모형에 더 큰 불이익을 줌

## 12. alpha

음이항 NB2 모형의 alpha는 과산포 정도를 나타내는 모수이다.

- `alpha ≈ 0`: 포아송 모형과 비슷한 분산 구조
- `alpha > 0`: 평균보다 큰 분산, 즉 과산포 존재
- alpha는 독립변수의 효과가 아니라 종속변수의 분산 구조를 설명한다.

## 13. Alpha=0 LR 검정

음이항 모형의 alpha가 0인지 검정하는 방법이다.

- 귀무가설: `alpha = 0`, 포아송 모형으로 충분
- 대립가설: `alpha > 0`, 과산포가 존재하므로 음이항 모형이 필요

p값이 0.05보다 작으면 포아송보다 음이항 모형이 필요하다는 근거가 된다. 같은 표본과 같은 설명변수로 비교해야 한다.

## 14. 수렴 여부

음이항 회귀는 최대우도법으로 모수를 추정하므로 최적화가 정상적으로 끝났는지 확인해야 한다.

- `converged=True`: 정상 수렴
- `warnflag=0`: 특별한 최적화 경고 없음
- `converged=False` 또는 `warnflag=1`: 결과를 바로 해석하지 말고 재추정

## 15. McFadden pseudo R²

상수항만 포함한 기준모형과 현재 모형의 로그우도를 비교한 지표이다.

`McFadden pseudo R² = 1 - (현재 모형 로그우도 / 기준모형 로그우도)`

값이 클수록 기준모형보다 적합도가 개선되었다는 뜻이다. OLS의 R²와 같은 의미는 아니므로 pseudo R² 하나만으로 모형을 판단하지 않는다.

## 17. 종속변수와 상대적 승차 변화 해석

본 연구의 종속변수는 `2025년 승차인원`이다. 종속변수를 처음부터 변화율로 바꾼 것은 아니다.

다만 모형에 `log(2024년 승차인원)`을 offset으로 넣었기 때문에 모형은 다음과 같은 구조를 가진다.

```text
log(2025년 예상 승차인원)
= log(2024년 승차인원) + 설명변수 효과
```

따라서 다음과 같이 해석할 수 있다.

```text
2025년 예상 승차인원 = 2024년 승차인원 × IRR
```

예를 들어 IRR이 0.8이면 2024년 승차인원이 100명인 경우 2025년 예상 승차인원은 약 80명이고, 50명인 경우 약 40명으로 예상된다. 즉 종속변수는 승차인원 수이지만, 2024년 기존 규모를 통제했기 때문에 IRR은 2024년 대비 2025년 승차 수준의 상대적 변화로 해석한다.

따라서 논문에서는 다음과 같이 표현한다.

> 종속변수는 2025년 승차인원이며, 2024년 승차인원을 offset으로 통제하여 설명변수의 효과를 2024년 대비 2025년 승차 수준의 상대적 변화로 해석하였다.

## 18. 표준화 모형과 표준화하지 않은 모형

표준화는 각 변수를 평균 0, 표준편차 1의 단위로 변환하는 것이다.

```text
표준화 변수 = (원래 값 - 평균) / 표준편차
```

### 표준화한 모형

연속형 변수의 1단위가 원자료의 1개, 1km, 1명이라는 뜻이 아니라 1표준편차라는 뜻이다.

- IC 거리 IRR: IC 거리가 1표준편차 증가할 때의 효과
- 인구 IRR: 인구가 1표준편차 증가할 때의 효과
- 건축물 수 IRR: 건축물 수가 1표준편차 증가할 때의 효과

장점은 변수들의 단위가 달라도 효과 크기를 비교하기 쉽고, 음이항 모형의 수렴이 안정될 수 있다는 점이다. 단점은 실제 정책·공간 단위로 해석하기 어렵다는 점이다.

### 표준화하지 않은 모형

연속형 변수가 원래 단위로 유지된다.

- 보행시간: 1분 증가
- IC 거리: 1km 증가
- 경쟁 목적지 비율: 1%p 증가
- 인구: 1명 증가
- 건축물 수: 1개 증가

장점은 결과를 실제 단위로 설명하기 쉽다는 점이다. 단점은 변수마다 단위가 다르므로 계수 크기를 단순 비교하기 어렵다는 점이다.

본 연구에서는 수렴과 모형 적합도가 동일하다면, 결과 설명이 쉬운 표준화하지 않은 모형을 본문에 제시하고 표준화 모형을 보조적으로 비교할 수 있다.

## 19. 본 연구에 적용한 해석 문장

> 종일 셀×노선 자료에서 Pearson dispersion과 Deviance/df가 1보다 크게 나타나 포아송 모형의 평균-분산 동일 가정이 충족되지 않았다. 이에 과산포를 고려할 수 있는 음이항 NB2 모형을 추정하고, alpha, Alpha=0 LR 검정, 로그우도, AIC·BIC, 수렴 여부를 확인하였다. 최종적으로 수렴한 모형의 IRR과 상대적 효과율을 이용해 GTX 접근성과 광역버스 승차인원 변화의 관계를 해석하였다.
