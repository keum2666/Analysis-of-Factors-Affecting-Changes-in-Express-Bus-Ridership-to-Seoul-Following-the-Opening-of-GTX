# GTX 머신러닝 예측단계 방법론 검토

현재 자료를 확인한 결과, **2025년 개통 후 승차인원을 직접 예측하는 방향은 연구 목적에 적합**합니다. Ridge Regression도 첫 후보로 타당하지만, 현재 표본에서는 기초 승차인원이 예측을 거의 지배하므로 Ridge를 바로 최종모형으로 확정해서는 안 됩니다.

간단한 역 권역별 검증을 시험해 보니, **2024년 승차인원에 학습자료의 평균 유지율만 곱한 단순 기준모형이 전체 변수를 사용한 Ridge보다 오차가 작았습니다.** 따라서 앞으로의 핵심은 복잡한 모델을 찾는 것이 아니라, GTX 접근성과 지역 특성이 이 강한 기준모형을 새로운 역 권역에서도 안정적으로 개선하는지 확인하는 것입니다.

## 2. 개통 후 승차인원을 종속변수로 쓰는 것이 적절한가

적절합니다. 현재 목적에는 다음 구조가 가장 자연스럽습니다.

$$
\widehat{Y}_{post,i}=f(Y_{pre,i},X_i)
$$

예측 후 다음 값을 계산합니다.

$$
\widehat{\Delta Y_i}=\widehat{Y}_{post,i}-Y_{pre,i}
$$

$$
예상변화율_i=\frac{\widehat{Y}_{post,i}-Y_{pre,i}}{Y_{pre,i}}\times100
$$

$$
예상유지율_i=\frac{\widehat{Y}_{post,i}}{Y_{pre,i}}\times100
$$

이 방식에는 세 가지 장점이 있습니다.

- 소규모 격자의 극단적인 변화율이 학습을 왜곡하는 문제를 줄입니다.
- 감소지역과 증가지역을 같은 모형으로 예측할 수 있습니다.
- 예측값이 실제 승차인원 단위이므로 정책적 해석이 쉽습니다.

단, 이 예측은 **GTX 개통의 인과효과 자체를 추정하는 모형은 아닙니다.** GTX-A에서 관측된 개통 전후 관계가 B·C 지역에도 유지된다는 전제 아래 이루어지는 전이 예측입니다.

현재 학습자료에는 2024년 승차인원이 0인 격자가 없습니다. 따라서 향후 GTX-B·C의 기초 승차인원이 0인 격자까지 예측하려면 별도 처리 규칙이나 학습표본 확장이 필요합니다. 기초 승차인원이 0이면 변화율과 유지율도 정의할 수 없습니다.

## 3. Ridge Regression 적용 타당성

### 타당한 점

- 126개 표본에 8~9개 변수면 단순한 선형모형을 추정할 수 있는 규모입니다.
- 변수 간 상관과 계수 불안정을 L2 규제로 완화할 수 있습니다.
- 트리 기반 복잡한 모델보다 작은 표본에서 과적합 위험이 낮습니다.
- 변수 표준화 후 사용하면 서로 다른 단위의 변수를 안정적으로 처리할 수 있습니다.
- GTX-B·C처럼 학습 범위를 벗어난 지역에 적용할 때, 복잡한 비선형 모델보다 결과를 점검하기 쉽습니다.

### 주의할 점

126행이라고 해서 독립적인 사례가 126개인 것은 아닙니다. 같은 역 주변의 인접 격자는 인구·토지이용·버스노선이 유사합니다. 실질적인 지역 맥락은 GTX-A의 3개 역 권역뿐이므로, **표본 수보다 역 권역 수가 더 큰 제약**입니다.

또한 종속변수의 분포가 1~608명으로 치우쳐 있어 직접 Ridge를 적용하면 다음 문제가 발생할 수 있습니다.

- 일부 격자에서 음수 예측 발생
- 대규모 승차 격자가 제곱오차를 지배
- 잔차 분산이 승차 규모에 따라 증가
- 규제 강도에 따라 결과가 크게 달라질 가능성

실제로 저장하지 않는 예비 계산으로 역 권역별 검증을 해본 결과는 다음과 같습니다.

| 예비 모형 | MAE | RMSE | R² | 음수 예측 |
|---|---:|---:|---:|---:|
| 2024 승차인원을 그대로 사용 | 97.9 | 213.8 | -5.39 | 0 |
| 학습 권역의 총 유지율 × 2024 승차 | 11.4 | 22.5 | 0.929 | 0 |
| 2024 승차만 사용한 Ridge | 11.7 | 22.3 | 0.930 | 0 |
| 후보 변수 전체 Ridge, α=1 | 14.8 | 24.0 | 0.919 | 18 |

이 계산은 하이퍼파라미터를 정식으로 선택한 최종 실험이 아닙니다. 다만 현재 자료에서 **기초 승차인원이 대부분의 예측력을 제공하며, 변수를 많이 넣는다고 자동으로 개선되지 않는다는 강한 신호**입니다.

따라서 비교 후보는 소수로 제한하는 것이 좋습니다.

1. 학습자료 평균 유지율을 사용하는 기준모형
2. 2024 승차인원만 사용한 Ridge
3. 2024 승차인원과 GTX·지역 변수를 사용한 Ridge
4. `log1p(승차인원)` Ridge 또는 Poisson/Tweedie 회귀

Poisson 또는 Tweedie 회귀는 예측값이 음수가 되지 않고 수요 규모에 따른 분산 증가를 다루기 좋습니다. Ridge를 주 후보로 두면서 이 중 하나를 민감도 비교모형으로 두는 정도면 충분합니다. Random Forest나 XGBoost는 현재 표본과 전이 목적에서는 우선순위가 낮습니다.

## 4. 권장 학습·검증 방법

### 1차 검증: GTX역 권역별 외부검증

사용자가 제안한 세 가지 분할을 주 검증으로 사용하는 것이 맞습니다.

- 운정중앙+킨텍스 학습 → 대곡 검증
- 운정중앙+대곡 학습 → 킨텍스 검증
- 킨텍스+대곡 학습 → 운정중앙 검증

이는 실제로 GTX-A 지역에서 학습한 모델을 새로운 B·C 역 권역에 옮기는 상황과 가장 유사합니다.

세 결과를 평균만 내지 말고 **각 역 결과와 전체 OOF 결과를 함께 보고**해야 합니다. 킨텍스는 승차 규모가 크기 때문에 하나의 전체 평균만 보면 권역별 실패를 놓칠 수 있습니다.

### 2차 검증: 공간 블록 교차검증

Ridge의 α를 정할 때 전체 126개를 무작위 K-Fold로 섞으면 인접 격자가 학습과 검증에 동시에 들어가 성능이 과대평가될 수 있습니다.

권장 방식은 다음과 같습니다.

- 위도·경도를 이용해 인접 격자를 4~6개 공간 블록으로 구성
- 같은 블록은 반드시 같은 fold에 배치
- 외부 LOSO 검증의 테스트 역은 α 선택 과정에서 사용하지 않음
- 남은 두 역의 공간 블록으로 α를 선택
- 선택된 α로 두 역 전체를 재학습한 뒤 제외한 역을 예측

일반 무작위 K-Fold 결과는 참고자료로만 제시하는 것이 좋습니다.

### 성능지표

| 지표 | 역할 |
|---|---|
| MAE | 주 평가지표. 격자당 평균 몇 명 틀렸는지 해석 가능 |
| Median AE | 극단적인 대규모 격자의 영향을 덜 받는 보조지표 |
| RMSE | 대규모 오차를 강하게 평가하는 보조지표 |
| R² | 설명되는 변동 수준. 외부검증에서는 음수도 가능 |
| WAPE | 전체 실제 수요 대비 총 절대오차 |
| 총량 오차 | 권역별 예측 승차 총합과 실제 총합 비교 |

MAPE는 기초 또는 실제 승차인원이 작은 격자 때문에 왜곡되므로 주 지표로 권장하지 않습니다.

모형 성능은 반드시 단순 기준모형 대비 개선량으로 표시해야 합니다.

$$
MAE\ 개선율=
\frac{MAE_{baseline}-MAE_{model}}{MAE_{baseline}}\times100
$$

이는 OLS와 Ridge를 비교하려는 것이 아니라, 추가 변수가 **실제 미래예측에 기여하는지** 확인하기 위한 절차입니다.

## 5. GTX-B·C 적용에 필요한 변수

| 변수 | B·C 구축 조건 |
|---|---|
| 개통 전 광역버스 승차인원 | A와 동일한 요일·집계시간·합성 방식 |
| GTX역 보행시간 | 동일한 ORS 설정과 역 출입구 기준 |
| IC 도로거리 | 같은 연도와 같은 공간자료·거리 산정법 |
| 20~50대 인구 | 개통 전 기준연도, 동일 SGIS 격자 |
| 평균 버스 통행시간 | 개통 전 승하차시각, 동일한 0~240분 처리 |
| 건축물 연면적 | 개통 전 기준연도, 동일 단위 |
| 주거지역 비율 | 동일한 용도지역 자료와 교차면적 방식 |
| 경쟁 목적지 비율 | A·B·C에 공통으로 적용할 정의를 새로 확정 |
| 격자 중심 좌표·최근접 역 | 공간 블록 검증과 적용 범위 점검용 |

### 보행 접근성

현재 20분 이내 격자가 11개뿐이라 `walk_20` 계수는 적은 사례에 의존합니다. 예측모형에서는 다음 두 표현을 사전에 정하고 비교하는 것이 좋습니다.

- 현재의 `walk_20`, `walk_20_60`
- 연속형 `log1p(walk_min)`

연속형 보행시간은 B·C에도 적용하기 쉽지만, Ridge에서는 보행시간과 수요의 관계를 직선으로 가정하게 됩니다. 결과를 본 뒤 임의로 15분·20분·30분 기준을 계속 바꾸면 과적합되므로 후보 형태를 사전에 제한해야 합니다.

### 경쟁 목적지 비율

현재 정의는 인수인계 문서와 코드상 다음과 같습니다.

> 2024년 서울행 광역버스 승객 중 연신내역 또는 서울역 1km 이내에서 하차한 승객의 비율

이 정의를 GTX-B·C에 그대로 적용하는 것은 적절하지 않습니다. B·C의 도심 측 정차역과 광역버스 목적지가 다르기 때문입니다.

공통 변수는 다음처럼 다시 정의하는 것이 좋습니다.

$$
경쟁목적지비율=
\frac{\text{개통 예정 GTX 노선의 도심측 역 영향권에서 하차한 개통 전 승객}}
{\text{하차좌표가 확인된 개통 전 광역버스 승객}}
\times100
$$

필요한 작업은 다음과 같습니다.

- A·B·C 노선별 도심 측 경쟁역 목록 확정
- 모든 노선에 동일한 1km 기준 또는 동일한 보행시간 기준 적용
- 환승역 포함 여부 사전 확정
- 새 정의로 GTX-A 변수도 다시 계산한 후 학습
- GTX-B·C도 개통 전 OD 자료만 사용하여 동일하게 계산

현재 A 전용 정의를 유지하면 `competing_share`가 노선 간 같은 의미를 갖지 않으므로 전이 예측의 타당성이 떨어집니다.

## 6. 주요 한계와 주의사항

- 학습된 지역 맥락은 GTX-A 3개 역뿐입니다. 126개 격자가 있어도 노선 간 일반화 근거는 제한적입니다.
- 승차인원은 교통카드 원자료가 아닌 합성자료입니다. 합성 과정의 오차까지 모델이 학습할 수 있습니다.
- 개통 전후 각각 하루만 비교하므로 날씨·행사·학교 일정·일시적 운행상황의 영향을 분리하기 어렵습니다.
- 117개 격자가 감소해 자료가 강한 전체 감소 패턴을 가집니다. B·C에서도 동일한 유지율이 발생한다는 보장은 없습니다.
- 현재 자료는 공급구조가 유지된 격자만 포함합니다. B·C에서도 버스 노선·운행횟수가 크게 개편되면 모형의 전제가 깨집니다.
- B·C의 변수 범위가 A 범위를 벗어나면 Ridge도 외삽예측을 하게 됩니다.
- 예측계수는 GTX 개통의 인과효과로 해석할 수 없습니다.
- 변화율과 유지율은 기초 승차가 작은 격자에서 여전히 불안정합니다. 최종 표에는 승차인원 10명 미만, 20명 미만 등의 경고표시가 필요합니다.
- 직접 Ridge를 사용하면 음수 예측이 생길 수 있습니다. 단순히 0으로 자르는 방법과 로그·Poisson 계열 모델의 결과를 비교해야 합니다.

GTX-B·C에 적용하기 전에는 각 변수에 대해 A 학습 범위와 B·C 범위를 비교해야 합니다. 범위를 벗어난 격자는 `외삽 주의`로 표시하고, 예측 순위와 수치를 별도로 해석하는 것이 안전합니다.

## 7. 실제 실험 단계

1. **분석용 마스터 테이블 확정**
   - 네 개 CSV를 셀 ID로 병합
   - 자료형·결측·중복 검증
   - 모든 변수의 기준연도와 생성 방법 기록

2. **경쟁 목적지 변수 재정의**
   - A·B·C 공통 알고리즘 확정
   - GTX-A 변수 재산출

3. **예측 대상과 적용 모집단 확정**
   - 공급구조 유지 격자만 예측할지 결정
   - 기초 승차 0인 격자의 포함 규칙 확정

4. **기준모형 평가**
   - 2024 승차 그대로 사용
   - 학습 권역 평균 유지율 적용
   - 2024 승차인원만 사용한 회귀

5. **소수의 후보모형 평가**
   - 전체 변수 Ridge
   - `log1p` Ridge
   - Poisson 또는 Tweedie 회귀
   - 변수 세트는 `기초 승차만 → 기초 승차+접근성 → 전체 변수` 순으로 비교

6. **공간 검증**
   - 주 검증: 3회 GTX역 LOSO
   - α 선택: 학습 역 내부 공간 블록 교차검증
   - MAE·Median AE·RMSE·R²·WAPE·권역 총량 오차 보고

7. **안정성 검토**
   - 보행시간 연속형과 더미형 비교
   - 저수요 격자 포함·제외 민감도
   - 큰 승차 격자의 영향 확인
   - 음수 예측과 잔차 공간분포 확인

8. **최종 GTX-A 모형 재학습**
   - 검증 결과가 기준모형을 일관되게 개선할 때만 전체 A 자료로 재학습
   - 개선하지 못하면 단순 유지율 모형도 정식 후보로 유지

9. **GTX-B·C 입력자료 구축 및 범위 검사**
   - A와 동일한 기준으로 개통 전 변수 생성
   - A의 최소·최대 및 분포와 비교
   - 외삽 격자 표시

10. **예측 결과 생성**
    - 개통 후 승차인원 예측
    - 변화량·변화율·유지율 계산
    - 저수요 및 외삽 경고 추가
    - 역 권역별 총량과 감소·증가 예상지역 지도화

현재 단계의 판단은 **Ridge를 주 실험 후보로 유지하되, 기준 유지율 모형과 2024 승차만 사용한 모형을 반드시 이겨야 채택한다**는 것입니다. 8~9개 변수를 넣을 수는 있지만, 현재 예비 결과로는 전체 변수가 예측을 개선한다는 근거가 아직 없습니다. 코드와 기존 데이터는 수정하지 않았습니다.
