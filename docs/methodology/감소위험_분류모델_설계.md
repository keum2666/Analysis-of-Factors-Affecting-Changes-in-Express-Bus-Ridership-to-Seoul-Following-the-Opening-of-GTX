> 관련 문서: `최종모형_v2.md`(영향요인 모형), `GTX-BC_적용성_검토.md`, `방법론_감사.md`

## 0. 결론 먼저

| 질문 | 답 |
|---|---|
| 가장 타당한 target | **T2: 10% 이상 감소** (변화율 ≤ −10%). 학습·평가는 **승객 수(2024 승차) 가중** |
| 가장 일반화가 잘 되는 모델 | **Ridge Logistic** (≈ 일반 Logistic). RandomForest·XGBoost는 일관되게 더 나쁨 |
| 가장 안정적인 변수 | **log(GTX역 보행시간) + IC 도로거리** 2개. 다른 변수는 더해도 개선이 없음 |
| 현재 성능 | 역 권역 검증 ROC-AUC **0.63** (fold 0.60~0.68), 3개 fold 중 2개는 95% 구간이 0.5를 포함 |
| B·C 적용 가능? | **아직 아니다.** 현재 수준에서는 '감소위험 등급'으로 발표하면 안 된다. 탐색적 상대 순위까지만 가능하다 |
| 가장 큰 원인 | 하루치 데이터의 **라벨 잡음**, 검증 권역이 **3곳뿐**, **철도 대안·노선 특성 변수 부재** |

**가장 중요한 발견**: 요청 사양 그대로(가중치 없음, 6변수) 돌리면 AUC가 0.48~0.62로 **예측력이 없다.** 원인은 모델이 아니라 라벨이다. 승차 1~4명짜리 셀×노선의 '감소' 여부는 우연이라, 모든 쌍을 똑같이 세는 분류모델은 잡음을 학습한다. **승객 수로 가중하면 세 권역 모두에서 0.60~0.68로 일관되게 올라간다.** 영향요인 모형(Poisson)이 승객 가중이어서 결과가 나왔던 것과 같은 이유다.

## 1. 종속변수(감소위험 라벨) 정의 — 가장 먼저 비교

### 이론적 비교
| 후보 | 정의 | 장점 | 문제 | B·C 적용성 |
|---|---|---|---|---|
| T1 단순 감소 | 2025 < 2024 | 가장 단순하다 | 1명 차이도 '감소'가 된다. 하루치 데이터에서는 잡음에 가장 민감하다 | 절대 기준이라 의미는 같다 |
| **T2 일정 감소율 이상** | 변화율 ≤ −10% (민감도: −20%) | 작은 우연 변동을 걸러낸다. 정책적으로 해석하기 쉽다("10% 이상 줄 곳") | 기준값(−10%)이 임의적이다 → 민감도 분석이 필요하다 | 절대 기준이라 B·C에서도 같은 의미다 |
| T3 분포 기반 | 변화율 하위 25% | 항상 25%라서 클래스 비율이 고정된다 | **A 표본 분포에 묶인 상대 기준**이다. B·C에는 개통 후 분포가 없어서 "하위 25%"를 정의할 수 없다. 사실상 예측 위험의 순위와 같다 | 라벨로서는 이전 불가 (출력 단계의 순위로만 의미) |
| 3단계 등급 | 예: ≤−30% 고 / −30~−10% 중 / >−10% 저 | 정책 등급과 바로 연결된다 | 클래스당 표본이 더 줄어든다(현재 186쌍). 순서형 모형이 필요하다 | 절대 기준이면 가능하다 |

### 실제 테스트 결과 (Ridge, 핵심2, 승객 가중, 역 권역 검증)
| target | 양성 비율 | 평균 ROC-AUC | fold별 (대곡 / 킨텍스 / 운정) | 계수 방향 |
|---|---|---|---|---|
| T1 | 66% | 0.61 | 0.53 / 0.61 / 0.70 | 가설과 일치 |
| **T2** | 63% | **0.63** | **0.60 / 0.62 / 0.68** | **가설과 일치** |
| T3 | 25% (킨텍스 11%) | 0.74 | 0.82 / 0.82 / 0.57 | **보행시간 반대** |

### 판단: **T2를 채택한다**
- fold 간 편차가 가장 작고(0.60~0.68), 계수 방향이 영향요인 모형과 같다.
- T3는 평균 AUC가 가장 높아 보이지만 믿을 수 없다.
  - 킨텍스 fold의 양성이 3개뿐이다.
  - 하위 25%가 '1명 → 0명(−100%)' 같은 소규모 쌍으로 채워진다.
  - 그 결과 보행시간 계수가 가설과 반대로 나온다.
  - B·C에서 정의할 수도 없다.
- 3단계 등급은 **라벨로 만들지 않는다.** 이진 T2 모형의 예측 위험을 **지역 내 분위로 나눠 등급화**한다(7번). 표본이 적어서 순서형 라벨은 아직 무리다.
- 추가로 권장: T2 기준을 −20%로도 돌려 민감도를 보고하고, 라벨 신뢰성 규칙(2024 승차 ≥ 5명 또는 승객 가중)을 고정한다.

## 2. 분석 단위

| 선택지 | 장점 | 단점 |
|---|---|---|
| **셀 × 노선 (권장: 학습 단위)** | 노선 특성 변수를 넣을 수 있다. 승객 가중이 자연스럽다. 영향요인 모형과 같은 단위다 | 쌍이 작아지면 라벨 잡음이 커진다 |
| 셀 | 라벨이 덜 흔들린다(셀 합계) | 노선 특성이 섞여 사라진다. 셀 안 노선별로 위험이 다른 것을 놓친다 |

**권장 설계**
- **학습·검증: 셀 × 노선, 승객 가중**
- **B·C 출력: 셀 × 노선 + 셀 단위 집계 둘 다.** 셀 위험 = 노선별 위험의 승차 가중 평균. 지도와 정책 해석에는 셀 단위가 쓰기 쉽다.

|---|---|---|---|---|---|
| **log(GTX역 보행시간)** | 핵심 가설. 역 접근이 쉬울수록 전환 | 셀 중심점 → 최근접 GTX-A역 ORS 보행시간 | 셀 중심점 → 최근접 **계획 B·C역(출입구)** ORS | ✅ (계획 역 위치) | **있음. 핵심 변수** |
| **IC 도로거리** | 버스의 고속도로 접근 = GTX 대비 시간 경쟁력 | 격자 → 최근접 IC 도로거리(km) | 같은 방식 | ✅ | **있음. 핵심 변수** |

| GTX 경쟁 목적지 비율 (현재 정의) | 목적지가 GTX로 대체 가능한가 | 2024 오전 승차 중 연신내·서울역 1km 하차 비율 | — | ✅ | 있음. **개선 없음** (T2 +0.016) → 재정의 필요 |
| **GTX 대체 가능 통행 비율** (재정의) | 위와 같지만 노선·구간 연결성까지 반영 | 출발·도착 정류장이 같은 GTX 노선의 개통 구간 역 도달권이면 대체 가능 | 계획 B·C 역과 구간으로 같은 계산 | ✅ (하차 좌표가 있는 개통 전 교통카드) | **미구축.** 정의는 `GTX-BC_적용성_검토.md` 3번 |
| **기존 철도역 접근성** | 이미 철도 대안이 있으면 GTX의 추가 효용이 작다 → 권역 간 기본 감소율 차이(대곡 52% vs 킨텍스 72%) 설명 후보 | 셀 → 최근접 지하철·광역철도역(3호선, 경의중앙선 등) 보행시간 | 같은 방식 (B·C는 기존 역과 겹치는 곳이 많아 특히 중요) | ✅ | **미구축. 1순위 추가** |

**사용하지 않는 것**: 노선 고정효과 값(B·C로 이전 불가), 개통 후 정보(공급구조 유지 필터 등).

## 4. 모델 후보

| 모델 | 역할 | 테스트 결과 (T2, 승객 가중, 핵심2 평균 AUC) | 이유 |
|---|---|---|---|
| **Ridge Logistic** | **메인** | 0.63 | 표본이 작아 안정적이고, 변수가 늘어날 때 과적합을 막는다. 계수 방향을 확인할 수 있다 |
| Logistic (규제 없음) | 기준선 | 0.64 | 변수 2개에서는 Ridge와 같다 |
| ElasticNet Logistic | 변수 선택 확인용 | 0.62 | 후보 변수가 많아질 때 어느 것이 남는지 본다 |
| RandomForest | 비교용 | 0.58 | 비선형 패턴이 있는지 확인한다. 현재는 이득 없음 |
| XGBoost | 비교용 | 0.54 | 186쌍 / 3권역에서는 과적합. Brier skill도 최저 |
| LightGBM | 보류 | — | XGBoost와 같은 이유. 데이터가 늘기 전까지 제외 |

설정: 선형 모델은 표준화 후 C=1 고정이다. 내부 튜닝을 하려면 학습 권역이 2개뿐이라 불안정하다. 데이터가 늘면 학습 권역 안에서 group CV로 C를 고른다. 승객 가중치는 **평균 1로 정규화**한다. 정규화하지 않으면 규제 강도가 바뀌고 saga solver가 수렴하지 않는다(실제로 확인함).

## 5. 검증 방법: leave-one-station-out

```
fold 1: 운정중앙 + 킨텍스 학습 → 대곡 검증     (학습 132쌍 / 검증 54쌍)
fold 2: 운정중앙 + 대곡   학습 → 킨텍스 검증   (150 / 36)
fold 3: 킨텍스  + 대곡   학습 → 운정중앙 검증  (90 / 96)
```

**B·C 외부 적용 검증으로 적절한가 — 방향은 맞지만 3가지 한계**
| 평가 | 내용 |
|---|---|
| ✅ 적절한 점 | 학습하지 않은 '지역'으로 옮기는 상황을 흉내 낸다. 랜덤 분할보다 훨씬 정직하다(랜덤 분할은 같은 권역 정보가 섞여 성능이 부풀려진다) |
| ⚠️ fold가 3개뿐 | 평균 AUC의 신뢰구간을 낼 수 없다. fold별 부트스트랩 구간도 넓다(대곡 0.38~0.77, 킨텍스 0.32~0.85, 운정 0.51~0.81) |
| ⚠️ 권역 크기 불균형 | 운정을 빼면 학습이 90쌍뿐이다. 킨텍스 검증은 36쌍이다. 소규모 권역 fold는 불안정하다 |
| ⚠️ B·C보다 쉬운 조건 | A 권역들은 노선을 공유한다(운정 검증 시 학습에 없던 노선 10개, 대곡 1개). B·C는 노선·도시 구조·GTX 서비스가 모두 다르다. 이 검증 성능이 B·C 성능의 **상한**에 가깝다 |

**보완 설계**
1. **GTX-A 동탄 구간(수서~동탄, 2024년 3월 개통)을 권역으로 추가**한다 → fold 4~5개. 성격이 다른 지역이 들어가 진짜 외부 검증에 가까워진다.
2. fold별 결과와 **부트스트랩 95% 구간**을 항상 같이 보고한다.
3. 보조 검증: 노선 그룹 단위 제외(같은 노선이 학습·검증에 동시에 있지 않게)를 해서 노선 특성 변수를 넣었을 때의 누설을 점검한다.

## 6. 평가지표

| 지표 | 역할 | 이유 |
|---|---|---|
| **승객 가중 ROC-AUC** | **핵심** | 용도가 '상대적 위험 순위'라서 순위 능력이 핵심이다. 승객 가중이어야 라벨 잡음에 흔들리지 않고 정책 관심(승객 수)과 맞는다. **0.7 이상, 모든 fold에서 95% 하한 > 0.5**를 적용 기준으로 둔다 |
| PR-AUC (+ 양성비율 기준선) | 보조 | 양성이 적은 target(T3, −20% 기준)에서 중요하다. 반드시 기준선(양성비율)과 같이 본다 |
| Brier skill | 보조 (보정) | 무정보 예측보다 나은지 본다. 0 이하면 확률로서 쓸모가 없다 |
| 지역 내 보정 곡선 | 진단 | 절대 확률은 권역 간에 맞지 않았다(대곡 Recall 0.10). 순위가 맞는지 확인하는 용도 |
| Precision / Recall @ 상위 25% | 정책 해석용 | "위험 상위 25%로 지정한 곳 중 실제 감소 비율"처럼 등급 산출 방식과 같은 기준으로 계산한다. 임계값이 0.5나 학습 평균이면 권역 간 기본 감소율 차이 때문에 왜곡된다 |
| Accuracy | **사용 안 함** | 양성이 63~66%라 무조건 '감소'로 찍어도 0.65가 나온다 |
| F1 | 사용 안 함 | 임계값에 따라 크게 바뀌고, 순위 용도와 맞지 않는다 |

## 7. B·C 적용 결과 형태

### 출력 테이블 (셀 × 노선)
| 컬럼 | 내용 |
|---|---|
| `region` | B 또는 C 영향권 시군 |
| `cell_id`, `route` | 셀 × 노선 |
| `base_boarding` | 개통 전 오전 승차(평일 여러 날 평균 권장). 가중치이자 신뢰도 표시 |
| `log_walk`, `ic_km`, (추가 변수) | 입력 변수 |
| `risk_score` | 선형 예측값 (logit) |
| `risk_prob` | 예측확률. **참고용**이고 A의 기본 감소율이 들어 있으므로 절대값을 해석하지 않는다 |
| `risk_pct` | **같은 B·C 노선축 안에서의 백분위** (승객 가중) |
| `risk_grade` | **상**: 상위 25% / **중**: 25~50% / **하**: 하위 50% |
| `flag_extrapolation` | 입력값이 A 학습 범위 밖이면 1 (예: B·C 역이 A보다 도심형이라 보행시간이 매우 짧음) |
| `flag_low_volume` | 개통 전 승차 < 5명이면 1 (등급 신뢰 낮음) |

### 셀 단위 집계
`cell_risk_pct` = 셀 안 노선별 `risk_score`의 승차 가중 평균을 다시 백분위로 바꾼 값. 등급 기준은 같다.

### 원칙
- 등급은 **지역 내 상대 순위**다. "상 등급 = 감소율 −X%"라고 해석하지 않는다.
- 모든 표와 지도에 **"GTX-A 기반 상대 위험 추정, B·C 개통 후 실측 검증 전"**이라고 표기한다.

## 8. GTX 접근취약지역 분석과 연결

### 유형 정의
- **감소위험**: `risk_grade` 상 = 높음, 중·하 = 낮음
- **GTX 접근성**: 최근접 GTX 역(계획) 보행 ≤ 25분 = 높음, 초과 = 낮음
  - 25분은 GTX-A 경계 곡선에서 효과가 유의했던 상한이다(`14_최종모형_v2_강건성` 6번). 연계교통(버스 환승) 기준 접근시간을 쓰는 확장도 가능하다.

| 유형 | 상황 해석 (가설) | 검토할 정책 방향 | 연구 설계상 확인할 것 |
|---|---|---|---|
| **① 위험 높음 + 접근성 높음** | 역 도보권이라 광역버스 수요가 GTX로 직접 넘어간다 | **광역버스 노선 조정**(GTX와 중복된 서울 직행 구간 감축·재배치) + 역 접근 보행환경 | 남는 버스 수요가 어느 목적지인지(GTX가 안 가는 곳) |
| **② 위험 높음 + 접근성 낮음** | 걸어서는 역에 가기 어렵지만, IC에서 멀어 버스가 원래 불리한 곳. 이탈한 승객이 환승·승용차로 GTX에 가거나 다른 수단으로 이동할 가능성 | **GTX 연계교통 강화**(역 연계 버스, 환승 할인, 환승주차장). 버스 감축은 신중하게 | 실제 이탈 경로(GTX 환승인지 승용차인지). 교통카드 환승 기록으로 A에서 확인 가능 |
| **③ 위험 낮음 + 접근성 낮음** | GTX 영향이 작고 광역버스가 계속 주 수단인 곳 = **GTX 사각지대** | **광역버스 유지·강화**(배차 유지, 서비스 개선). 장기적으로 GTX 연계 수요 조사 | 이 지역 주민의 GTX 이용 의향(설문·연계 수요) |
| **④ 위험 낮음 + 접근성 높음** | 역 근처인데도 버스가 유지될 것으로 보이는 곳. 버스 목적지가 GTX와 다르거나 버스가 시간 경쟁력이 있음 | **광역버스 유지** + 모니터링. 개통 후 실측으로 모형 검증 우선 대상 | 모형이 틀릴 가능성이 가장 높은 유형이다. 개통 후 실측 비교 1순위 |

> 이 유형화는 **정책 검토 대상을 고르는 틀**이지, 정책 효과를 추정하는 것은 아니다. 각 유형의 정책 방향은 후속 연구(수요조사, 개통 후 실측)로 검증해야 한다.

## 9. 제약 조건 반영

| 제약 | 설계 반영 |
|---|---|
| B·C 정답 데이터 없음 | 성능은 A 내부 역 권역 검증으로만 주장한다. B·C 결과는 실측 전 추정으로 표기한다 |
| A 내부 외부적용성 최대 검증 | leave-one-station-out + 부트스트랩 구간 + 동탄 구간 추가(권장) + 노선 그룹 제외(보조) |
| 노선 FE 값 이전 금지 | 분류모델에 노선 FE를 넣지 않는다. 노선 특성 변수로 대체한다 |
| 수치 예측이 아닌 상대 위험 | 출력은 지역 내 백분위 등급이다. 확률은 참고용이다 |
