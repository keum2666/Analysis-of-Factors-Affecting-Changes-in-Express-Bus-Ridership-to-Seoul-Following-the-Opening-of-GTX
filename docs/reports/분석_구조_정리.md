# GTX-A 광역버스 승차 변화 연구 파일 정리

## 1. 현재 최종 연구 설계

- 공간 단위: 250m 격자
- 분석 대상: 2024·2025년 공급구조가 동일한 132개 셀
- 본 분석 시간대: 07:00~09:59
- 종속변수: `2025년 승차인원 - 2024년 승차인원`
- 본모형: 전체 132개 셀 OLS + HC3
- 보조모형 1: 승차 감소 여부 로지스틱 회귀
- 보조모형 2: 감소 셀만 대상으로 감소규모 회귀
- 보조모형 3: 보행시간 연속형과 10분·15분 역세권 더미 비교
- GTFS: 방향 구분 문제로 현재 분석에서 제외

## 3. 현재 회귀모형 후보

### 본모형

```text
Y = 07~09시 승차인원 증감
X = GTX 보행시간
  + IC 접근성
  + GTX 경쟁 목적지 비율
  + 2024년 20~50대 인구
  + 2024년 건축물 수
```

고령인구는 20~50대 인구와 상관이 높으므로 본모형에 동시에 넣지 않고 대안모형으로 비교한다.

### 보조모형

1. 전체 132개 셀 OLS + HC3
2. 감소 여부 로지스틱 회귀
3. 감소 셀 79개 감소규모 회귀
4. 보행시간 연속형·10분 더미·15분 더미 비교
5. 필요 시 분위수 회귀

## 4. 지금은 사용하지 않는 파일·분석

- GTFS 오전 운행횟수 피처: 서울행 방향 구분이 불완전하여 제외
- 500m 분석: 본모형이 아니라 보조 분석
- 공시지가 변화율: 본모형에서 우선 제외
- GTX 직선거리: 보행시간과 중복 가능성이 있어 본모형에서 제외
- 하루 전체 변화량: 오전 통근시간 분석의 강건성 검토용
- 초기 04-2 ORS POST 방식: 현재 사용하는 04-3 GET 결과와 구분

## 5. 연구 스토리

> GTX-A 개통 이후 광역버스 승차 변화가 모든 격자에서 동일하게 나타났는지 확인하고, GTX역 접근성과 지역 교통·인구 특성이 광역버스 감소지역 및 감소규모와 어떤 관련이 있는지 분석한다.

정확한 승차인원 예측보다는 `감소가 발생한 지역`과 `감소폭이 큰 지역`을 식별하는 연구로 해석한다. GTX-B·C에는 정확한 인원 예측보다 감소 가능지역·교통 취약지역 식별 결과를 적용한다.
